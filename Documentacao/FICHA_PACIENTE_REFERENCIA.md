# Referência — Ficha do Paciente (Simples Dental)

## Estrutura da Ficha

### Abas
1. **Sobre** — Dados pessoais, plano, comunicação
2. **Orçamentos** — Lista de orçamentos com valor e status
3. **Tratamentos** — Odontograma + lista + evoluções
4. **Anamnese**
5. **Imagens**
6. **Documentos** — Contrato, Termo, Receituário, Atestados
7. **Débitos** — Total recebido vs a receber

### Layout Tratamentos (2 painéis)
- **Esquerda 70%**: Adicionar tratamento + Odontograma + Lista tratamentos
- **Direita 30%**: Evoluções
